Internship Engine

Privacy notice

Last updated: October 22, 2026

This notice describes the Internship Engine browser extension, which works with the hosted web app alone or with the optional local Internship Engine app.

Browser app

The no-install app at /app/ stores your profile, resume text, and tracker in this browser's local storage. It does not send that information to a server. It downloads the shared job feed to show current roles; if you import a PDF resume, the app reads it in your browser. The page loads its fonts from Google Fonts and, only when you import a PDF, the pdf.js reader from cdnjs; those services see a normal web request, never your resume or tracker.

Information the extension handles

On supported job-board pages, the extension reads the page URL, job-posting details, and visible application-field labels and options so it can show fit information, save a role, and prepare answers from your profile. In web-app-only mode, it receives your profile from the hosted app and lets you select a resume PDF in the extension popup. In laptop-engine mode, it can use your local profile and resume.

Where information goes

The extension stores its profile, selected resume PDF, learned answers, queued events, and optional local-engine token in chrome.storage.local. In web-app-only mode, profile and event messages are exchanged with the hosted app page; extension data is not uploaded to a server. In laptop-engine mode, the extension sends the page and form details needed for its features to your own local engine at 127.0.0.1:8765. It does not send this data to the project maintainers or a project-operated server.

If you choose to submit an application, the application site receives the information in the form you reviewed. The extension itself never clicks Submit.

Optional features

The local app can optionally read Gmail using credentials you configure, and can import a LinkedIn connections export for local matching. These are separate local-app features; the browser extension does not send those files to the project maintainers.

Retention and control

The extension's profile, selected resume PDF, learned answers, queued events, and engine token are stored in Chrome's local extension storage. In laptop-engine mode, your profile, resume, tracker, and optional imports are stored on your own computer in data/. Remove the extension or clear its storage to remove its data; delete the local files yourself to remove local-app data.

Changes and contact

Changes to this notice will be published on this page. For questions or privacy concerns, open an issue in the GitHub repository.
