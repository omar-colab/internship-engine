Internship Engine

Privacy notice

Last updated: October 22, 2026

This notice describes the Internship Engine browser extension and its connection to the optional local Internship Engine app. The software is open source and runs on your computer.

Information the extension handles

On supported job-board pages, the extension reads the page URL, job-posting details, and visible application-field labels and options so it can look up a role, save it, and request answers from your local profile. When you choose to fill a form with a resume field, the extension retrieves your resume from the local app and places it in that page's file field.

Where information goes

The extension sends the information needed for these actions only to the local app at 127.0.0.1:8765, using a token stored in Chrome's local extension storage. The extension does not send your profile, resume, application fields, or browsing history to the project maintainers or a project-operated server. The local app stores personal files in the repository's ignored data/ directory.

If you choose to submit an application, the application site receives the information in the form you reviewed. The extension itself never clicks Submit.

Optional features

The local app can optionally read Gmail using credentials you configure, and can import a LinkedIn connections export for local matching. These are separate local-app features; the browser extension does not send those files to the project maintainers.

Retention and control

Your engine token is stored in Chrome's local extension storage. Your profile, resume, tracker, and optional imports are stored on your own computer in data/. Remove the extension or clear its storage to remove the token; delete the local files yourself to remove app data.

Changes and contact

Changes to this notice will be published on this page. For questions or privacy concerns, open an issue in the GitHub repository.
