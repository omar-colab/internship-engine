02 — Match score

A percentage you can check, point by point.

Every role gets a score out of 100, built from four parts. Each point comes with a reason from your profile or the posting. No black box, no mystery model.

35pts

Role fit

Does the title and the work match the fields you picked?

30pts

Skills

Which skills the posting asks for are on your resume, named one by one.

20pts

Location

In one of your cities, remote, or somewhere you'd rather not move.

15pts

Timing & eligibility

The right season and class year. Graduate-only roles are flagged, not hidden in the fine print.

05 — Rules it never breaks

It takes the busywork. Never your judgment.

These hold in the browser app, the laptop engine and the extension.

Rule 1

It never clicks Submit

Every application ends with you reading it and pressing the button yourself.

Rule 2

It never invents

Every answer points at your profile, a line in your resume, or an answer you gave yourself. No backing, no answer.

Rule 3

It never pretends to be you

No CAPTCHA solving, no LinkedIn automation, no sending messages. Drafts only.

06 — Laptop version

Run it on your laptop for the power tools.

Optional. Install the engine and Chrome extension for daily inbox tracking and application autofill that stops before Submit.

Find

Reads Workday, Greenhouse, Lever, Ashby, iCIMS, UKG, Oracle Cloud, Phenom, SuccessFactors, Jobvite, JazzHR and Workable boards directly, plus public internship lists. Any company it meets once gets watched from then on.

Rank

Every posting is read in full and scored against your resume, with the reason in one line. Graduate-only roles, the wrong class year and seasons already past are hidden before you see them.

Your answers

Answer a question once and it's reused when the same question, word for word, comes back. Essays come back as a draft for you to edit, never filled. SSN, birth date, bank and login answers are never saved.

Fill the forms other autofills give up on

It clicks through to the real form, opens every dropdown to read the hidden options, types into search-as-you-type fields, attaches your resume, then checks each answer stuck. Anything your resume doesn't back is left for you, never guessed. Then it stops, and you press Submit.

Setup

Three steps on a Mac or Linux laptop.

You need Chrome and uv. Claude Code is optional for assisted setup.

01

Get the engine

Clone the repo, install it, and copy the example profile.

git clone https://github.com/omar-colab/internship-engine
cd internship-engine
uv sync
mkdir -p data
cp profile.example.json data/profile.json
02

Tell it about you

Edit data/profile.json with your information. Or use Claude Code's optional /setup flow to build the profile from your resume and run your first search.

03

Add the extension

Download the latest GitHub Release, extract it, and load the folder containing manifest.json from chrome://extensions with Developer mode on. Paste your token from engine token.
